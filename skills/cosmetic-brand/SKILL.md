# cosmetic-brand

이름과 병이 고객이 기억하는 약속이다. 이 스킬은 앞 스킬들이 찾은 빈자리와 구매자의 말에
맞춰 이름, 세계관, 카피 방향, 패키지 브리프를 만든다. 예쁜 무드보드가 목적이 아니다.

사용자가 `/cosmetic-brand` 뒤에 쓴 것: `$ARGUMENTS`

## 공통 규칙 (모든 cosmetic-* 스킬)

- 작업 폴더는 `cosmetic/<프로젝트-슬러그>/`다. 어느 프로젝트인지 확인한다.
- 사실이 아닌 것을 만들지 않는다. 추정은 '가설', 모르는 것은 '확인 필요'. 숫자는
  출처와 확인일.
- 경쟁사 문구를 베끼지 않는다. 효능, 1위, 근거 없는 수치를 만들지 않는다.
- beauty-data MCP는 있으면 쓰고 없으면 공개 웹으로 내려간다. MCP 데이터(카피 원문,
  OCR, 처방, 공급사, 가격)는 내부용이고 외부 게시물에 옮기지 않는다.

## Step 1: 읽기

`brief.md`(만들고 싶은 느낌, 사용자 말), `competitors.md`(이미 남의 것이 된 단어와 모양,
빈자리), `panel/results.md`(사는 이유·안 사는 이유), `formula.md`(성상, 향, 컨셉 원료),
`claims.md`(쓰지 않는 말), `pricing.md`(가격대). 브랜드가 이미 있는 회사 브랜드면 그
브랜드의 기존 라인업과 이름 문법을 사용자에게 받거나, MCP가 있으면
`riselab_search_products`로 사내 제품명을 찾아 겹치지 않게 한다.

## Step 2: 라인업 안에서의 자리

- 이 제품이 브랜드 안에서 어떤 라인인지, 다른 라인과 무엇이 다른지 세 줄.
- 세계관: 한 줄 컨셉, 세 가지 태도(각각 하는 것과 하지 않는 것), 장면(누가, 언제, 어디서).
- 향이 여러 개면 향을 묶는 체계(시간대, 방, 장소, 번호 등)를 하나 고른다.

## Step 3: 이름 후보

시리즈명, 제품명, 향명을 각각 다양한 방식으로 열 개 안팎(서술형, 연상형, 조어, 번호
체계). 후보마다: 읽히는 뜻, 소리 내어 읽기(국문 발음), 1도 인쇄·작은 라벨에서의 모양,
기존 라인과의 문법, 걸리는 점. 그다음 세 개로 줄이고 사용자가 고르게 한다.

줄인 세 개마다 사용자가 직접 끝낼 확인:

- **상표:** KIPRIS(kipris.or.kr)에서 국내 상표를 **3류**(화장품)로 검색한다. 같은 이름,
  비슷한 이름, 같은 발음을 본다. 3류의 지정상품과 유사군 코드는 KIPRIS 화면에서 확인한다.
  수출 계획이 있으면 해당 나라 상표청(미국 USPTO, EU EUIPO 등)도.
- **식별력:** 흔한 단어 하나면 등록이 어려울 수 있다고 적는다(판단은 변리사).
- **혼동:** `competitors.md`의 이름, 사내 기존 제품명과 겹치지 않는지.
- **도메인·핸들:** 필요하면 자사몰 경로, 인스타그램 핸들.

공개 검색까지만 할 수 있고, 등록 가능 여부는 변리사가 판단하며, 출원하기 전에는 아무것도
등록된 게 아니라고 분명히 말한다.

## Step 4: 카피 방향

- **원칙** 세 줄: 무엇으로 말하고 무엇으로 말하지 않는지.
- **헤드라인 후보** 세 개. 모두 `/cosmetic-claims`를 거쳐야 쓴다(`claims.csv` 상태 표시).
- **바디 카피의 결:** 문장 길이, 형용사, 시점. `pitch.md`의 한 줄을 전/후로 다시 써 보인다.
- **쓰지 않는 말:** `claims.md`의 목록 + 경쟁사가 선점한 단어 + 세계관과 안 맞는 말.
- 내부 레퍼런스(참고 브랜드, 무드 출처)는 기획 문서에만 두고 외부 카피에 쓰지 않는다.

## Step 5: 패키지 디자인 브리프

`cosmetic/<슬러그>/design-brief.md`. 디자인 담당 에이전트가 이 파일 하나로 시안을 시작할 수
있게 쓴다.

```
# 패키지 디자인 브리프: <제품명>

## 제품
- 브랜드 / 시리즈 / 제품명 / 향명(들) / 용량 / 표시 유형(예: 바디워시) (확정/후보 표시)

## 용기
- 형태와 용기 코드(있으면), 재질, 색·투명도, 마감, 캡·펌프, 충진 여유
- 단상자 유무, 라벨인지 직접 인쇄인지, 인쇄 방식과 도수 (예: 실크 1도)

## 컬러
- 2~3색, 각각의 역할, 향별 구분 방법. 인쇄 방식에서 재현 가능한지 확인 필요

## 조판 방향
- 서체 성격(예: 에디토리얼 세리프 + 가는 그로테스크), 위계, 여백, 로고 크기
- 사용할 서체의 라이선스 확인

## 들어가야 할 것
- 필수 표시사항 공간(전성분, 용량, 제조번호, 사용기한, 책임판매업자 등). 목록과 크기는 RA 확인 필요
- 기능성이면 기능성 표시 문구 자리 (보고 완료 후)

## 쓰지 않는 말·요소
- claims.md의 금지 표현, 숫자 배지, 경쟁사와 닮은 요소

## 레퍼런스 (내부용)
- 무드 레퍼런스, 이전 시안 링크. 외부 카피에 쓰지 않음

## 넘겨받을 것
- 시안 개수, 파일 형식, 용기별 목업, 결정할 사람과 날짜
```

## 규칙

- 경쟁사의 이름, 로고, 컬러 조합, 카피를 베끼지 않는다.
- 권리가 없는 서체·이미지·아이콘을 쓰지 않는다.
- 이미지 생성 도구로 만든 시안은 '콘셉트'라고 표시한다. 완성 디자인이 아니다.
- 상표에 대한 법률 자문이 아니다.

## 출력

`cosmetic/<슬러그>/brand.md`(세계관, 이름 후보와 확인 목록, 카피 방향),
`cosmetic/<슬러그>/design-brief.md`. 다음: `/cosmetic-marketing`.
